# Adjudication protocol
For each criterion, determine the best-fit markband and within-band mark from source evidence.
Check primary and auditor claims, explain any mark difference, and state the strongest reason
the final mark is not higher. Do not impose universal thresholds or reward irrelevant features.
When an image or calculation cannot be verified, say **"not evidenced in the available source"**
and recommend human review if it could change a mark.

Every material final-mark claim needs **Page N**, **Pages N–M**, or an exact digest page label.
Put only verbatim IA text, from the cited page, inside quotation marks.
Never invent a value, source location or figure label. Keep visual-analysis hints separate.
